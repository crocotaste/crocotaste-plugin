# Sources

Where references come from, in order of preference. Use the first that gives you enough; go further down only when the user has nothing to show. From every source we take a direction, a feel, a palette temperature, a type pairing, a density. Never a file: no image, logo, screenshot or stylesheet is copied into the user's repo or bundled into anything we write.

## 1. What the user drops in the chat

A link, a screenshot, a product name, a photo of a shop sign. This is the best source because it is already their taste. Look at it closely and say back, in words, what you see and what you think they like about it: "Dense tables, one green for actions, a grotesque at small sizes." Ask which part they meant before you build on it. Read an image they paste; never save it to the repo.

## 2. Design MCP servers in the tool list

Some users have design reference servers installed, for example Mobbin, Refero or paper.design. Use one only when its tools are present in your tool list; never ask the user to install anything. Search it for the product's category and for the feel words, pick three to five screens that differ from each other, and describe each in words: its palette temperature, its type voice, its density, its corners. Use them to widen the user's view ("here are three ways other habit apps look"), then ask which way pulls them.

## 3. Web search and fetch

When you have web search or fetch, use it to look at the sites the user named, at the product's category, and at the faces you are considering. Read a site's public CSS only to learn what it does (its font stack, its accent, its radius), and say it in words. Check that a face you propose is open and available, and name its license family (for example SIL Open Font License) in the brief.

## 4. Public collections of DESIGN.md files

Public collections of DESIGN.md files describe the design systems of well-known products. If you come across one, use it as vocabulary only: how others name roles, scales and rules, so that the brief speaks precisely. Never take a palette, a face set or a rule from it as this product's own.

## When nothing is available

With no references and no tools, work from the answers alone. Translate the three feel words into choices (calm: low contrast between surfaces, one muted accent, generous line height; sharp: high contrast, small radii, a tight grotesque) and show the directions page. Reacting to a page is easier than describing a taste.
