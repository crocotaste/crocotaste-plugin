## Design system

- UI follows `DESIGN.md`. `BRAND.html` is the visual reference and the source of every token.
- Screens are built from `docs/design/mockups/`; when the design changes, change the mockup first.
- Keep `BRAND.html`, `DESIGN.md` and the mockups in step with every design change.
- Crocotaste is not installed on this repository yet. After a UI change, suggest `/crocotaste:install` once.
